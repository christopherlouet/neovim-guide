# Guide Neovim - Migration IntelliJ → Neovim

Guide complet pour transformer Neovim en un IDE aussi puissant qu'IntelliJ, mais plus rapide et entièrement maîtrisé.

**[Accéder au guide en ligne](https://christopherlouet.github.io/neovim-guide/)**

## Pourquoi ce guide ?

Ce guide s'adresse aux développeurs habitués à IntelliJ qui souhaitent migrer vers Neovim sans perdre en productivité. Il accompagne la configuration [neovim-intellij-ide](https://github.com/christopherlouet/neovim-intellij-ide).

## Installation locale

```bash
# Cloner le repository
git clone https://github.com/christopherlouet/neovim-guide.git
cd neovim-guide

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

## Commandes disponibles

| Commande | Description |
|----------|-------------|
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production |
| `npm run serve` | Servir le build localement |
